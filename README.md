# 批量IP线路测试筛选工具 (AS58807/AS9929/AS4809)


📢 项目简介
本项目基于 NTrace-core (NextTrace 核心库) 进行二次开发。NTrace-core 是一个现代化的开源路由追踪核心库，以其高性能和可扩展性著称。
针对网络优化和 VPS 测评场景，本版本对核心逻辑进行了深度定制，将其改造为一款自动化批量线路筛选工具。旨在帮助用户从海量 IP 列表中，快速识别并筛选出经过特定优质骨干网（如 CN2 GIA, CUII, CN2 GT）的节点。
✨ 核心功能更新
🎯 特定 AS 线路智能筛选
内置优质 AS 库：集成了对以下三大热门优化线路的自动识别逻辑：
AS58807：中国移动 （低延迟、高稳定性）。
AS9929：中国联通 （高端优化线路）。
AS4809：中国电信 （CN2 GT/GIA 59.43和202.97的核心段）。
路径匹配算法：在路由追踪过程中，自动分析每一跳的 AS 信息，一旦路径中包含上述任一 AS 号，即判定为“优化线路”。
📊 IP 批量自动化测试
批量处理模式：支持导入 IP 列表文件，自动循环执行路由追踪任务，无需人工逐个输入。
结果自动过滤：程序会自动丢弃普通线路的测试结果，仅输出命中目标 AS 的优质线路详情，极大提升选路效率。
进度可视化：在批量测试过程中提供实时进度反馈，方便监控任务状态。
🛠️ 适用场景
测试cloudflare的ip的路由走向
网络运维：批量排查内网或外网 IP 的路由走向，确认是否回传至优化骨干网。
📝 使用提示
输入格式：支持标准 IP 列表文本。
权限要求：Windows 版本建议右键“以管理员身份运行”，以确保 ICMP/TCP 追踪的准确性。
